# F15 chord layer

Native support for an **F15-held chord layer** + **double-tap-F15 leader**, replacing the external Hammerspoon setup.

F15 is not a macOS modifier, so Carbon's `RegisterEventHotKey` can't express "hold F15 + key". This uses a **CGEvent tap** instead (like the windows you map RCmd→F15 via Karabiner).

## Behavior
- **Hold F15 + key** → run a nehir command.
- **Double-tap F15** → open the [Leader](leader.md) tab of the Command Palette.

## Default chord map (v1, hardcoded)
Mirrors the old Hammerspoon bindings:

| Key | Action |
|-----|--------|
| `h` `l` `j` `k` | focus left / right / down / up |
| `⇧h` `⇧l` `⇧j` `⇧k` | move window left / right / down / up |
| `f` | toggle column full width |
| `c` | expand column to available width |
| `0` | cycle column width |
| `-` | consume window into column |
| `=` | expel window from column |
| `esc` | cancel the layer |

> The chord list is hardcoded for now (TOML-configurable chords are deferred — see the `// ponytail:` note in `NehirF15ChordEngine.swift`). The leader (double-tap) menu *is* fully configurable; see [leader.md](leader.md).

## Config (`~/.config/nehir/settings.toml`)
```toml
[general]
f15Enabled = true          # default false
f15DoubleTapSeconds = 0.3  # double-tap window
```

## Permissions
The tap needs **Input Monitoring** (Privacy & Security → Input Monitoring), separate from Accessibility. Enabling F15 prompts for it once. Without the grant the tap simply isn't installed — F15 does nothing, everything else keeps working (no crash).

## Implementation
- `Sources/Nehir/Core/Input/NehirF15ChordEngine.swift` — pure state machine: hold tracking (3s stale-timeout), chord lookup, double-tap detection, escape cancel. Unit-tested (`Tests/NehirTests/NehirF15ChordEngineTests.swift`).
- `Sources/Nehir/Core/Input/F15EventTap.swift` — `@MainActor` CGEvent-tap owner; re-enables on `tapDisabledByTimeout`, dispatches through the same path as Carbon hotkeys.
- Wired in `WMController.reconcileEnabledAndHotkeysState()` (installs when enabled + app active).
